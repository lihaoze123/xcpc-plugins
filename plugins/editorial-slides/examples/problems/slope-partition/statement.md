给定长度为 $n$ 的正整数序列 $a_1, a_2, \dots, a_n$ 以及固定常数 $C$。

你需要将序列划分为若干连续非空段。若某一段包含元素 $[l, r]$，其代价为 $\left(\sum_{k=l}^{r} a_k\right)^2 + C$。求最小总代价。

## 输入格式

第一行包含两个整数 $n, C$（$1 \le n \le 5 \times 10^5$，$0 \le C \le 10^{12}$）。

第二行包含 $n$ 个正整数 $a_1, a_2, \dots, a_n$（$1 \le a_i \le 10^4$）。

## 输出格式

输出一行一个整数，表示最小总代价。
